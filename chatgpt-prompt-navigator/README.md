# ChatGPT Prompt Navigator

本地 Chrome / Edge 扩展，用于长 ChatGPT 对话的稳定目录和快速跳转。

## v1.4.1 侧边栏快捷键

- 新增 `Alt + \`：切换展开或收起“我的提问”侧边栏。
- 保留鼠标按钮，两种方式共享展开状态；不改变提问索引、筛选内容和原有跳转快捷键。

## v1.4.0 虚拟列表闭环导航

针对“远处尚未渲染的提问跳不过去、失败后又回到底部、原本能跳的提问随后失效”的问题：

- 不再把虚拟列表中的 DOM Element 长期保存在目录项里；每次跳转和高亮都按 API `message.id` 重新查询当前 DOM。
- 若目标 UUID 当前已渲染，直接 `scrollIntoView()` 精确定位。
- 若目标尚未渲染，不再按“第 N 问 / 总问数”猜页面百分比；改为读取当前已渲染提问的 API 序号范围，判断目标在历史方向还是新消息方向。
- 每次只沿正确方向移动约一屏，等待 ChatGPT 完成虚拟化后重新读取 DOM，再决定下一步，直到目标真实出现。
- 对 `.thread-scroll-container` 的 `flex-direction: column-reverse` 使用负向历史滚动区间，不再来回尝试多个绝对比例。
- 任一时刻只允许一个导航会话；点击新目录项会取消旧导航的全部定时步骤。
- 导航期间 MutationObserver 只记录“稍后刷新”，不会重建目录与导航流程互相打架。
- 用户手动滚轮、触摸或点击聊天区域时会立即取消自动导航，避免插件抢夺滚动位置。
- 达到边界或连续无进展时直接停止在已到达位置，不再自动弹回聊天底部。
- 状态中的“当前 x/y”表示此刻 ChatGPT 实际挂载、可立即定位的用户提问数量，不要求一直等于全部目录数。

## v1.3.0 新版 ChatGPT DOM 精确导航

根据 2026-09-25 当前 ChatGPT 页面实际结构适配：

- 用户消息单元使用 `[data-chatgpt-search-unit-key$=":user"]`。
- `data-chatgpt-search-message-ids` 与完整会话 API 的用户 `message.id` UUID 直接一一对应。
- 外层 `[data-turn-key]` 使用同一个用户消息 UUID，可作为轮次级备用锚点。
- 用户气泡 `[data-user-message-bubble="true"]` 可作为新版结构识别辅助。
- 主聊天滚动容器明确使用 `.thread-scroll-container`，且当前为 `flex-direction: column-reverse`。
- 点击目录、`Alt+↑/↓`、`Alt+Home/End` 优先用消息 UUID 精确绑定后调用原生 `scrollIntoView()`，不再假设普通 `scrollTop` 方向。
- 当前提问高亮根据已绑定用户消息节点在真实聊天滚动视口中的位置判断。
- 旧属性匹配和正文文本匹配只保留为兼容/兜底方案。

## v1.2.0 关键改进

针对 ChatGPT 前端移除旧的 `conversation-turn-*` / `data-message-author-role` 标记后的兼容性问题：

- 完整会话 API 现在是目录主数据源；API 有多少条用户提问，目录就显示多少条。
- DOM 不再决定目录是否存在，只作为可选“跳转锚点”。
- 状态改为“17条 · 锚点0/17”这类形式，能区分“目录完整”和“页面锚点完整”。
- 页面没有旧属性时，会按当前可见正文做文本匹配，自动绑定能识别到的提问。
- 无锚点的提问仍然保留；点击后先按会话位置渐进滚动，再尝试重新绑定正文。
- 去掉“API 条数必须等于 DOM 条数”以及因此产生的自动重复读取，降低触发 429 的风险。

## v1.1.0 关键改进

ChatGPT 的长聊天会虚拟化渲染：远离当前视口的消息正文会被卸载，但 conversation-turn 外壳仍然保留。v1.1.0 不再只扫描当前已挂载的消息，而是：

- 用持久的 `conversation-turn-N` 外壳固定全部用户提问的数量、顺序和跳转锚点。
- 对标准 `/c/<id>` 聊天做一次只读、同源读取，补齐未挂载提问的完整文本。
- 已经从 DOM 看到过的提问文本会留在本次页面会话缓存中，不会因为消息正文卸载而从目录消失。
- 点击目录或使用快捷键后会多次重新校准滚动位置，降低虚拟化重新布局造成的偏移。
- 顶部 `↻` 可手动重新读取当前聊天的完整索引。

## 快捷键

- `Alt + ↑`：上一条我的提问
- `Alt + ↓`：下一条我的提问
- `Alt + Home`：第一条我的提问
- `Alt + End`：最后一条我的提问
- `Alt + \`：收起或展开侧边导航栏

## 其他功能

- 右侧自动生成“我的提问”目录，点击即可跳转。
- 顶部可按关键词筛选当前聊天中的提问。
- 目录可收起/展开。
- ChatGPT 内切换聊天后自动清理旧索引并重建新聊天目录。
- 跨聊天继续建议使用 ChatGPT 自带的 `Ctrl + K`。

## 隐私与网络

扩展没有遥测、第三方请求或远程脚本，也不会把聊天内容保存或上传到任何第三方。

为了绕过 ChatGPT 长聊天的 DOM 虚拟化，v1.1.0 会对当前 ChatGPT 自己的同一站点发起只读 GET：

- `/api/auth/session`：读取当前登录会话令牌。
- `/backend-api/conversation/<id>`：读取当前聊天本身已经加载的完整会话数据。

令牌只保存在当前页面脚本内存中，不写入扩展存储。若这两个内部接口未来变化或读取失败，扩展会自动退回“turn 外壳 + 已见 DOM 文本缓存”模式，目录数量仍尽量保持稳定。

## 安装 / 更新

Edge：打开 `edge://extensions/`；Chrome：打开 `chrome://extensions/`。

首次安装：开启开发者模式 → “加载解压缩的扩展” → 选择：

`P:\2609233CG_webcodex\chatgpt-prompt-navigator`

已经安装旧版时：在扩展管理页找到 ChatGPT Prompt Navigator，点击“重新加载”，然后刷新 ChatGPT 页面。

如果 ChatGPT 后续修改内部 DOM 或内部会话接口，扩展可能需要同步调整。
