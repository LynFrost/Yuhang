# 语航：侧边提问导航栏快捷键（v1.4.1）

## 1. 背景与目标

ChatGPT Prompt Navigator 当前通过右侧按钮收起或展开“我的提问”侧边导航栏，也已支持 `Alt + ↑`、`Alt + ↓`、`Alt + Home`、`Alt + End` 等提问跳转快捷键。

为减少鼠标操作，新增一个简单、可重复使用的快捷键，在展开和收起之间切换。此次属于小范围体验优化，不改变现有提问索引和导航机制。

## 2. 实施范围

- 代码仓库：`LynFrost/Yuhang`
- 开发分支：`feature/v0.0.1`（独立于 `main`）
- 本文档：`docs/v1.4.1-sidebar-toggle-hotkey.md`（仓库根目录下的 `docs`）
- 插件目录：`chatgpt-prompt-navigator/`
- 当前扩展版本：`1.4.1`（版本号与 Git 分支名称分开管理）

## 3. 需求

### 3.1 快捷键

- 使用 **`Alt + \`**（Alt + 反斜杠）作为“展开 / 收起侧边导航栏”的唯一切换快捷键。
- 导航栏已展开时按下快捷键：收起。
- 导航栏已收起时按下快捷键：展开。
- 同一快捷键反复按下可以反复切换，无需额外的打开键或关闭键。
- 保留现有右侧收起/展开按钮，两种触发方式必须同步到同一状态。

### 3.2 保持现有行为

- 收起仅隐藏导航面板，不删除或重建提问索引。
- 收起与展开不清空搜索框、不改变当前选中的提问、不取消或重置现有导航过程。
- `Alt + ↑`、`Alt + ↓`、`Alt + Home`、`Alt + End` 原有功能保持不变；侧边栏隐藏时仍可正常使用。
- 快捷键仅在扩展注入的 ChatGPT 页面生效，不注册操作系统或其他网页的全局热键。
- 更新界面提示与插件 README，使用户知道新快捷键。

### 3.3 按键冲突与边界

- 只有符合 `Alt + \` 的按键组合才执行切换；不能把单独的反斜杠误判为快捷键。
- 与 `Ctrl` / `Meta` 同时按下时，不触发本功能。
- 与原有四组导航快捷键保持独立，不改变它们的按键和行为。
- 通过现有 `keydown` 监听处理，触发时阻止该事件的默认行为及向后传播（与原有导航快捷键一致）。
- Chrome / Edge 的实际系统、扩展、输入法快捷键组合可能产生冲突，最终以本机浏览器实测为准。

## 4. 设计与实现范围

尽量复用现有功能，不引入依赖、不改变架构：

1. `chatgpt-prompt-navigator/content.js`
   - 把现有收起/展开按钮中的状态切换提取为可复用逻辑；
   - 在 `handleKeyboard(event)` 增加 `Alt + \` 判断，调用相同的切换逻辑；
   - 更新按钮提示和侧栏底部快捷键说明。
2. `chatgpt-prompt-navigator/README.md`
   - 在快捷键表中补充 `Alt + \`；
   - 简要记录本次变更。
3. `chatgpt-prompt-navigator/manifest.json`
   - `manifest.json` 中的插件版本设置为 `1.4.1`。

不修改 `styles.css`、不增加新权限、不改动会话 API 与虚拟列表导航流程。

## 5. 验收标准

- [ ] 展开状态按 `Alt + \`，侧边栏收起。
- [ ] 收起状态按 `Alt + \`，侧边栏展开。
- [ ] 连续反复按键，显示状态正确，不出现不同步。
- [ ] 鼠标按钮和快捷键交替操作，仍保持一致。
- [ ] 展开/收起前后的关键词筛选内容保持不变。
- [ ] 侧边栏收起状态下，四组既有提问导航快捷键仍可使用。
- [ ] 在 ChatGPT 页面切换会话后，快捷键仍能切换侧边栏。
- [ ] 普通输入反斜杠以及 `Ctrl + Alt + \` 不触发切换。
- [ ] Chrome 与 Edge 中进行手工回归检查。

## 6. 非目标

本次不增加自定义快捷键设置界面、不注册 `chrome.commands`、不做跨网页或系统级快捷键，也不处理其他新功能。

## 7. 开发顺序

1. 在 `feature/v0.0.1` 分支先提交本需求文档。
2. 按文档实现最小代码修改和文档更新。
3. 检查差异，验证 `main` 未受影响。
4. 实际浏览器交互测试由安装并运行扩展的用户确认。
