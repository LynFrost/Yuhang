# 语航：侧边导航栏快捷键调整为 Alt + Q（v1.4.3）

## 一、背景与目标

ChatGPT Prompt Navigator 当前插件版本为 **1.4.2**。v1.4.2 将侧边栏展开/收起快捷键从 `Alt + \` 调整为 `Alt + X`。现决定进一步将该切换快捷键改为 **`Alt + Q`**，统一保持左手单手操作体验。

本次只更换切换快捷键，不重构侧边栏、不改变提问目录索引、虚拟列表导航或其他快捷键。

## 二、实施信息

- 仓库：`LynFrost/Yuhang`
- 开发分支：`1.4.3`（完整分支名；区别于仓库中另外存在的 `feature/v1.4.3`）
- 基线：`main` 当前 v1.4.2 代码
- 本文档路径：`docs/v1.4.3-alt-q-sidebar-toggle.md`
- 计划发布版本：`1.4.3`
- **本次仅落本文档，不修改任何代码、README 或 manifest，不更新实际插件版本。**

## 三、功能需求

1. 侧边导航栏从展开切换到收起、或从收起切换到展开的快捷键统一为 **`Alt + Q`**。
2. **取消原 `Alt + X` 触发功能**，也不恢复更早的 `Alt + \`，即仅保留一个侧边栏切换快捷键。
3. 保留原鼠标按钮；按键与鼠标入口继续共同调用 `toggleSidebar()`，状态保持一致。
4. 切换侧边栏时，搜索关键字、提问列表、选中项及导航过程保持原有行为。
5. 保持既有 `Alt + ↑`、`Alt + ↓`、`Alt + Home`、`Alt + End` 提问导航快捷键不变，即使侧边栏处于收起状态也应正常。
6. 仅在当前扩展注入的 ChatGPT 页面内生效，不新增系统级或浏览器全局快捷键注册。

## 四、按键识别与冲突处理

- 计划沿用当前 v1.4.2 的按键处理方式：已有 `handleKeyboard(event)` 首先要求 `event.altKey` 为真，并排除 Ctrl、Meta 及输入法组合输入阶段。
- 将现有的 `event.code === "KeyX"` 条件调整为 `event.code === "KeyQ"`，以识别键盘物理 Q 键；不依赖字母大小写。
- 维持 `event.shiftKey` 和 `event.repeat` 排除逻辑，避免组合键误触及按住按键反复切换。
- 确认有效后，继续执行 `toggleSidebar()`、`event.preventDefault()`、`event.stopPropagation()`，并返回，不进入其他导航按键分支。
- 单独 Q、`Ctrl + Q`、`Ctrl + Alt + Q`、`Alt + Shift + Q` 都不应切换。
- 在 ChatGPT 输入框有焦点时，`Alt + Q` 仍可切换；普通字母 Q 输入不应受影响。
- `Alt + Q` 可能与操作系统、输入法、其他扩展或应用的快捷键冲突：文档不预设“无冲突”，需实际在 Chrome / Edge 及用户使用的 Windows 环境中测试。

## 六、验收标准（后续代码修改后验证）

- [ ] 展开状态按一次 `Alt + Q` 能收起侧边栏。
- [ ] 收起状态按一次 `Alt + Q` 能展开侧边栏。
- [ ] 反复按键及与鼠标收起/展开按钮交替操作时，状态一致。
- [ ] 长按 `Alt + Q` 不因键盘重复事件导致侧边栏反复闪动。
- [ ] `Alt + X`、`Alt + \` 不再触发侧边栏切换。
- [ ] 普通 Q 输入、`Ctrl + Q`、`Ctrl + Alt + Q`、`Alt + Shift + Q` 不触发切换。
- [ ] 在 ChatGPT 输入框有焦点时普通输入不受影响，`Alt + Q` 可切换。
- [ ] 收起/展开不改变搜索关键词、当前选中提问及提问索引。
- [ ] 原四组提问导航快捷键继续正常工作。
- [ ] Chrome 和 Edge 中实际测试常用输入法、浏览器、截图及其他软件可能存在的快捷键冲突。
- [ ] 版本配置、插件和仓库 README、UI 提示一致显示 v1.4.3 / `Alt + Q`。
