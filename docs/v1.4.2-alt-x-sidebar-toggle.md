# 语航：侧边提问导航栏快捷键优化（v1.4.2）

## 1. 背景与目标

ChatGPT Prompt Navigator v1.4.1 已支持通过 `Alt + \` 展开或收起“我的提问”侧边导航栏。但在常见键盘布局下，反斜杠键距离左侧 Alt 较远，操作时往往需要双手配合，不适合高频使用。

本次将侧边栏切换快捷键由 `Alt + \` **替换为** `Alt + X`，以提升单手操作便利性。仅改变快捷键入口，不改变目录、提问定位、虚拟列表导航及展开/收起的既有行为。

## 3. 功能需求

### 3.1 新快捷键

- 使用 **`Alt + X`** 作为展开 / 收起侧边栏的切换快捷键。
- 当前展开时按一次：收起；当前收起时按一次：展开。
- 连续多次单独按下快捷键，可以稳定往复切换。
- 不再保留 `Alt + \` 的侧边栏切换功能，避免产生两个入口。
- 原有鼠标收起/展开按钮继续有效，与快捷键使用同一状态与切换逻辑。

### 3.2 保持原有功能

- 收起或展开不清空搜索框内容，不删除提问索引，不改变选中项。
- 原有 `Alt + ↑`、`Alt + ↓`、`Alt + Home`、`Alt + End` 快捷键保持不变，在侧边栏收起时仍能正常操作。
- 切换聊天、主题变化、目录刷新及虚拟列表渐进导航逻辑不作改动。
- 快捷键只在扩展注入的 ChatGPT 网页内响应，不新增全局快捷键或权限。

### 3.3 触发条件与边界

- 以 `event.altKey` 与 `event.code === "KeyX"` 判断左侧字母 X 的物理按键，避免大小写和部分键盘布局产生的 `event.key` 差异。
- 当 Ctrl、Meta、Shift 同时按下、处于输入法组合输入阶段（`event.isComposing`），或按住 X 产生自动重复事件（`event.repeat`）时，不触发该切换功能。
- 单独按 X、`Ctrl + X`、`Ctrl + Alt + X`、`Alt + Shift + X` 均不切换。
- 当 ChatGPT 输入框获得焦点时，`Alt + X` 仍按上述条件切换侧边栏；普通输入 X 不受影响。
- 处理成功时沿用已有键盘事件的 `preventDefault()` 和 `stopPropagation()` 行为。
- 浏览器、其他扩展及输入法可能拦截某些组合键，最终效果应在目标 Windows/Chrome/Edge 环境中实际验证。

## 4. 计划修改位置（后续实施；本阶段不执行）

### 4.1 `chatgpt-prompt-navigator/content.js`

- `handleKeyboard(event)`：将现有的 `case "\\"` 切换逻辑替换为识别 `Alt + X` 的条件；继续调用现成的 `toggleSidebar()`。
- 仅对新增快捷键应用 `Shift` 排除和 `repeat` 排除，避免意外改变原有上下提问导航按键的行为。
- 导航按钮的 `title` 和侧边栏底部的快捷键说明：将 `Alt+\` 改为 `Alt+X`。
- 不修改侧边栏 CSS、渲染机制、读取会话接口或其他快捷键的跳转实现。
